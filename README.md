# Лабораторная работа №3. REST API

## Тема

Расчёт ежемесячных процентных выплат по банковскому вкладу.

## Стек

- Go
- Gin
- GORM
- PostgreSQL
- MinIO
- Docker
- Postman

## Структура backend

Приложение построено по схеме:

`Handler → Repository → Model → PostgreSQL`

Для работы с базой данных используется ORM GORM.

Данные веб-сервиса передаются в формате JSON.  
Все методы REST API имеют префикс `/api`.

## Методы API

### Услуги

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/deposit-months` | Получение списка опубликованных расчётных месяцев с фильтрацией |
| GET | `/api/deposit-months/feed` | Получение элемента ленты |
| GET | `/api/deposit-months/draft` | Получение черновика текущего пользователя |
| POST | `/api/deposit-months` | Создание черновика и загрузка изображения и видео |
| PUT | `/api/deposit-months/draft` | Публикация черновика |
| DELETE | `/api/deposit-months/:id` | Логическое удаление собственной услуги |
| POST | `/api/deposit-months/:id/like` | Установка или снятие лайка |

### Пользователи

| Метод | URL | Назначение |
|---|---|---|
| POST | `/api/users` | Регистрация пользователя |
| POST | `/api/users/authentication` | Заглушка аутентификации |
| POST | `/api/users/deauthentication` | Заглушка деавторизации |

## Параметры запросов

### Фильтрация списка

`GET /api/deposit-months`

Поддерживаемые query-параметры:

- `min_days_count` — минимальное количество дней;
- `max_days_count` — максимальное количество дней.

Пример:

```text
/api/deposit-months?min_days_count=28&max_days_count=31
```

В ответе для каждой услуги передаётся признак `is_creator` со значением `0` или `1`.

### Лента

`GET /api/deposit-months/feed`

Без параметров возвращается первый опубликованный элемент ленты.

Для получения следующего элемента используются:

```text
id=<ID>&next=true
```

Пример:

```text
/api/deposit-months/feed?id=5&next=true
```

В ответе передаётся признак `is_liked` со значением `0` или `1`.

### Лайк

`POST /api/deposit-months/:id/like`

Тело запроса:

```json
{
  "liked": 1
}
```

`liked = 1` — поставить лайк.  
`liked = 0` — удалить лайк.

## Загрузка файлов

При создании услуги изображение и видео передаются как файлы с помощью `multipart/form-data`.

Файлы сохраняются в MinIO.  
Ссылки на изображение и видео сохраняются в базе данных.

## Текущий пользователь

В лабораторной работе полноценная авторизация ещё не используется.

Текущий пользователь фиксирован:

```text
currentUserID = 1
```

Доступ к идентификатору текущего пользователя выполняется через singleton-функцию `GetCurrentUserID()`.

Текущий пользователь используется при:

- определении автора услуги;
- работе с черновиком;
- удалении собственной услуги;
- установке и снятии лайка.

## Таблицы базы данных

### `users`

Хранит пользователей системы.

Основные поля:

| Поле | Назначение |
|---|---|
| `id` | Первичный ключ |
| `full_name` | ФИО пользователя |
| `birth_date` | Дата рождения |
| `email` | Электронная почта |
| `password` | Пароль |

### `deposit_months`

Хранит расчётные месяцы.

Основные поля:

| Поле | Назначение |
|---|---|
| `id` | Первичный ключ |
| `name` | Название |
| `description` | Описание |
| `status` | Статус записи |
| `image_url` | Ссылка на изображение |
| `video_url` | Ссылка на видео |
| `month_number` | Номер месяца |
| `days_count` | Количество дней |
| `creator_id` | Создатель |
| `created_at` | Дата создания |
| `formed_at` | Дата публикации |

Возможные статусы:

```text
draft
published
deleted
```

Удаление является логическим: запись остаётся в базе данных, а её статус меняется на `deleted`.

### `deposit_month_likes`

Хранит лайки пользователей.

Основные поля:

| Поле | Назначение |
|---|---|
| `id` | Первичный ключ |
| `user_id` | Пользователь |
| `deposit_month_id` | Расчётный месяц |

Один пользователь может поставить одной услуге не более одного лайка.

## Запуск проекта

Запустить PostgreSQL и Adminer:

```bash
docker compose up -d postgres adminer
```

При необходимости запустить MinIO:

```bash
docker start minio_storage
```

Запустить backend:

```bash
go run ./cmd/deposit_month
```

API доступен по адресу:

```text
http://localhost:8080/api
```

Adminer:

```text
http://localhost:8081
```

MinIO Console:

```text
http://localhost:9001
```
